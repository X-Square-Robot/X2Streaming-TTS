# Hugging Face model-card sources

These cards belong to the two official `x-square-robot` model repositories.
The source cards were refreshed from their public repositories on 2026-09-14.
Weights, configurations, checksums and weight licenses are not modified.

Build the starter with `python3 tools/quickstart/build_starter.py`, then run
`python3 tools/publish_hf_docs.py` in an environment with `huggingface_hub`.
Log in with an account that can write to the official repositories first.
Only model cards, the original recording and the starter ZIP are uploaded.
